# ALTN Ne Kadar (altnnekadar.com)

Türkiye’de altın fiyatları konusunda kullanıcıya faydalı, hızlı, mobil uyumlu, SEO dostu ve Google AdSense politikalarına uygun statik web platformu.

## 🚀 Teknolojiler
- HTML5 (Semantik & SEO Uyumlu)
- CSS3 (Duyarlı Tasarım, Dark/Light Tema)
- Vanilla JavaScript (ES6+, Bağımsız Modüler Mimari)
- GitHub Pages Uyumlu Statik Yapı
